# Helbaron — محرر Markdown بالعربي

Helbaron نسخة خاصة مبنية على المشروع مفتوح المصدر Markra، ومعدّلة لتكون محرر Markdown حديث بدعم كامل للعربية.

## الجديد في هذه النسخة

### 1. العربية أولاً
- **واجهة عربية كاملة**، وهي لغة البرنامج الافتراضية. ترجمنا أكثر من 1000 عبارة، ومعها قوائم النظام.
- **الواجهة كلها من اليمين إلى اليسار**: الشريط الجانبي والقوائم والإعدادات ومفاتيح التشغيل وسحب تغيير الحجم.
- **خطوط عربية مدمجة** (Noto Sans Arabic وNoto Naskh Arabic)، فيظهر العريض والعناوين بشكل صحيح.

### 2. اتجاه ذكي لكل فقرة
- كل فقرة تأخذ اتجاهها حسب **اللغة الغالبة عليها**. الفقرة العربية تُكتب من اليمين حتى لو بدأت بكلمة إنجليزية، مثل «Helbaron محرر…».
- الكود يبقى دائماً من اليسار إلى اليمين.
- الجداول العربية تترتب أعمدتها من اليمين.
- يمكنك فرض اتجاه واحد على المستند كله من شريط الأدوات: تلقائي، أو يمين، أو يسار.

### 3. شريط أدوات للتنسيق
تراجع وإعادة، نمط الفقرة (نص عادي أو عنوان من 1 إلى 6)، عريض، مائل، يتوسطه خط، تظليل، كود، مسح التنسيق، قوائم نقطية ومرقمة وقائمة مهام، اقتباس، كتلة كود، رابط، صورة، جدول، خط فاصل، اتجاه النص، فتح ملف Word، تصدير إلى Word، وطباعة أو PDF.

### 4. Word مدمج ولا يحتاج Pandoc
- **فتح ملفات .docx**: تتحول إلى Markdown، ومعها العناوين والقوائم والجداول والعريض والمائل والروابط والصور.
- **تصدير إلى .docx**: الفقرات العربية تخرج من اليمين إلى اليسار في Word، والجداول العربية معكوسة، والقوائم مرقمة.

## التثبيت على ويندوز

### الطريقة الأسهل: المثبّت الجاهز
شغّل الملف `Helbaron_2.14.0_x64-setup.exe`، واختر مجلد التثبيت على قرص D عندما يطلب منك ذلك.

> ⚠️ المثبّت غير موقّع رقمياً، فقد يظهر تحذير SmartScreen. اضغط «More info» ثم «Run anyway».

### البناء من الكود بنفسك
افتح PowerShell داخل مجلد المشروع وشغّل:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\windows\build-helbaron.ps1
```

السكربت يثبّت الأدوات ومجلدات الكاش كلها على **D:\dev**. لاستخدام قرص آخر:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\windows\build-helbaron.ps1 -ToolsRoot E:\dev
```

المتطلبات: Node.js 22، وأدوات Microsoft C++ Build Tools (اختر «Desktop development with C++»). السكربت يثبّت Rust وpnpm تلقائياً.

### تجربة سريعة في المتصفح (للمطوّر)
```bash
pnpm install
pnpm --filter @helbaron/web dev
```

## ملاحظات

- **الترخيص**: Markra مرخّص بـ AGPL-3.0، وهذه النسخة تلتزم بنفس الترخيص. إذا وزّعت البرنامج أو قدمته كخدمة، فيجب أن تتيح الكود المعدّل.
- **التحديث التلقائي معطّل** حتى لا تستبدل تحديثات Markra الأصلية نسختك.
- **روابط المشروع الأصلي بقيت كما هي** (GitHub والموقع وملفات قاموس التدقيق الإملائي)، لأن تغيير اسمها يجعلها روابط معطّلة.
- **لا يوجد قاموس تدقيق إملائي عربي بعد**، والكلمات الإنجليزية داخل النص العربي يتم تدقيقها.
