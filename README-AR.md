يحفظ Helbaron كتاباتك كملفات `.md` عادية على جهازك، بينما تكتب على صفحة تبدو كمستند منسّق: العناوين والجداول والكود والمعادلات والمخططات تظهر أثناء الكتابة. افتح ملف Word وأكمل تحريره كـ Markdown، ثم صدّره إلى Word أو PDF عندما تريد مشاركته. العربية والإنجليزية في المستند نفسه، وكل فقرة تأخذ اتجاهها تلقائياً.

لا حساب، ولا سحابة. ملفاتك تبقى ملكك.

## التنزيل

| النظام | الملف |
| --- | --- |
| ويندوز 10 / 11 | `Helbaron_x64-setup.exe` |
| ماك (Apple Silicon وIntel) | `.dmg` |
| لينكس | `.AppImage` أو `.deb` |

كل الملفات في صفحة [الإصدارات](https://github.com/Hassan-elbaron/helbaron/releases/latest).

> قد يظهر تحذير SmartScreen أو Gatekeeper في أول تشغيل. على ويندوز اختر **More info ثم Run anyway**، وعلى ماك انقر بالزر الأيمن على البرنامج واختر **Open**.

بعد التثبيت يظهر Helbaron في قائمة **فتح بواسطة** لملفات `.md` و`.markdown` و`.txt` و`.docx`.

## المميزات

- **صفحة وليست صندوق نص:** معاينة فورية للعناوين والقوائم والجداول والصور والمعادلات والمخططات، مع شريط أدوات واحد وقائمتي «إدراج» و«عرض».
- **Word يدخل ويخرج:** افتح ملفات `.docx` من البرنامج أو من مستكشف الملفات مباشرة، وصدّر إلى Word أو PDF أو صفحة ويب. الفقرات العربية تبقى من اليمين إلى اليسار في Word.
- **العربية كما يجب:**
  - كل فقرة تختار اتجاهها، فتعمل المستندات المختلطة بلا إعدادات.
  - طباعة عربية مضبوطة: تشكيل صحيح للحروف، وبلا تباعد بين الحروف، ومسافة أكبر بين الأسطر للتشكيل.
  - البحث يتجاهل الحركات ويوحّد أشكال الحروف: `احمد` تجد `أحمد`، و`مدرسه` تجد `مدرسة`.
  - واجهة عربية كاملة بضغطة زر، والإنجليزية هي الافتراضية.
- **بالشكل الذي تحبه:** خمسة أشكال للواجهة لكل منها نسخة فاتحة وداكنة: Baron وGlass وSlate وPaper وMinimal. تختار شكلك في أول تشغيل مع معاينة حية.
- **ملفاتك على جهازك:** مجلدات وتبويبات وبحث في المجلد، وحفظ تلقائي، وسجل إصدارات، ونسخ احتياطي، ومزامنة WebDAV اختيارية.
- **مساعد كتابة اختياري** يعمل مع OpenAI وAnthropic وGemini والنماذج المحلية. لا يعمل حتى تضيف مزوّداً، وكل تعديل يظهر كمعاينة قبل قبوله.

## البناء من المصدر

المتطلبات: Node.js 24 وpnpm 10 وRust.

```sh
git clone https://github.com/Hassan-elbaron/helbaron.git
cd helbaron
pnpm install
pnpm --filter @helbaron/desktop tauri dev
```
